# AI 智能助手 CLI（AI Assistant CLI）

基于大模型 **Function Calling（函数调用）** 实现的命令行智能助手。模型自动理解用户意图并决定是否调用工具、调用哪个工具、调用几次；Python 代码负责真正执行函数并把结果回传，模型再基于结果生成自然语言回答。

支持多轮对话上下文记忆、连续工具调用，内置天气查询、数学计算、时间查询三个工具。

---

## 功能特性

- **多轮对话**：维护完整对话历史，助手记得上下文（如先问"北京天气"，再问"要带伞吗"能接上）
- **工具自动选择**：无需手动指定，模型根据问题自动选择工具（问天气 → 天气工具，问计算 → 计算器）
- **连续工具调用**：一次提问可触发多轮工具调用（如"北京和上海哪个热"会连续查询两个城市）
- **三个内置工具**：
  - `get_weather(city)`：城市天气查询（当前为模拟数据，可替换为真实天气 API）
  - `calculate(a, b, operator)`：精确数学计算（加减乘除）
  - `get_current_time()`：当前日期、时间、星期查询（无参数工具示例）
- **对话管理命令**：输入 `clear` 清空历史重新开始，输入 `退出` 结束程序

---

## 工作原理

Function Calling 的核心分工：**模型负责决策，代码负责执行**。

```
用户提问
   │
   ▼
┌──────────────────────────────────┐
│  外层循环：多轮对话                │
│  input 接收输入 → 维护 messages    │
└───────────────┬──────────────────┘
                │
                ▼
┌──────────────────────────────────┐
│  内层循环：Agent 工具调用闭环       │
│                                  │
│  ① 请求模型（messages + tools）    │
│        │                         │
│   ┌────┴─────────┐               │
│   ▼              ▼               │
│ 模型返回 tool_calls   模型直接回答 │
│   │              │               │
│   ▼              │               │
│ ② 执行 Python 函数 │              │
│ ③ 结果作为 tool 消息回传          │
│   │              │               │
│   └──► 回到 ① 再请求   打印答案，break
└──────────────────────────────────┘
                │
                ▼
        回到外层循环，等待下一句
```

**关键设计：**

1. **tools 工具说明书**：用 JSON Schema 向模型描述每个函数的名称、功能、参数。模型靠 `description` 判断何时该用哪个工具
2. **双层循环架构**：外层管理对话状态，内层处理"模型可能连续 N 次调用工具才肯回答"的情况
3. **四种消息角色**：`system`（助手设定）、`user`（用户输入）、`assistant`（模型回复，含工具调用指令）、`tool`（函数执行结果）
4. **安全实践**：API Key 通过 `.env` 文件管理，不写入代码

## 快速开始

### 环境要求

- Python 3.10+
- 智谱 AI API Key（GLM-4-Flash 模型免费，注册即得：https://open.bigmodel.cn/ ）

### 安装

```bash
pip install openai python-dotenv
```

### 配置

在项目根目录创建 `.env` 文件：

```
ZHIPU_API_KEY=你的API密钥
```

> 确保 `.gitignore` 中包含 `.env`，避免密钥泄露。

### 运行

```bash
python day18_assistant.py
```

## 使用示例

```
========================================
智能助手已启动！
输入 clear 清空对话历史，输入 退出 结束
========================================

你：现在几点了？
[系统] 正在调用 get_current_time，参数 {} ...
AI：现在是 2026年9月2日 14:20，星期二。

你：杭州天气怎么样？
[系统] 正在调用 get_weather，参数 {'city': '杭州'} ...
AI：杭州今天晴天，气温 28 度，天气不错。

你：3827乘以941等于多少？
[系统] 正在调用 calculate，参数 {'a': 3827, 'b': 941, 'operator': '*'} ...
AI：3827 × 941 = 3601207。

你：北京和上海哪个温度高？
[系统] 正在调用 get_weather，参数 {'city': '北京'} ...
[系统] 正在调用 get_weather，参数 {'city': '上海'} ...
AI：北京 22 度，上海 26 度，上海更热。

你：那我出门要带伞吗？
AI：北京有小雨，建议带伞；上海多云不用。
```

## 可扩展方向

- 将 `get_weather` 内部替换为真实天气 API（如和风天气、高德天气）
- 增加更多工具：网页搜索、文件读写、数据库查询、邮件发送
- 接入流式输出（stream=True）实现打字机效果
- 异常重试：网络抖动时自动重试 API 请求
- 用 FastAPI 封装为 Web 服务，提供 HTTP 接口
