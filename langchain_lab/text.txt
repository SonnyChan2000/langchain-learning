一句话： Document Loader（文档加载器）是 LangChain 的"万能读卡器"——把不同类型的外部数据
（PDF、CSV、网页、Word、数据库…）读进来，统一成一种标准结构 Document 。

新建 51_pdf_loader.py ：
python
from langchain_community.document_loaders import PyPDFLoader
loader = PyPDFLoader("test.pdf") # 指向你的 PDF 文件
docs = loader.load() # 加载全部，返回页面列表
print(f"共加载了 {len(docs)} 页")
print("=== 第1页内容（前300字）===")
print(docs[0].page_content[:300])
print("=== 第1页元信息 ===")
print(docs[0].metadata)
跑通标准： 打印出 共加载了 N 页 、第 1 页开头文字、以及 metadata（里面应有 source: test.pdf
和 page: 0 ）。
概念点（背）：
• PyPDFLoader 按页切分：一页 → 一个 Document （ mode 参数可设 "single" 整篇一个）。
• docs[0].page_content 取第 1 页正文， docs[0].metadata 取第 1 页元信息。

from langchain_community.document_loaders import WebBaseLoader

print(docs[0].page_content[:500])

Q：在用 LangChain 做 RAG 吗？介绍一下加载文档这块。
A：RAG 的第一步是文档加载，LangChain 的 Document Loader 负责把我各种格式的数据统一读成标准
的 Document 对象（正文 + 元信息）。我实际加载过 PDF（按页切，带页码元信息）、CSV（按行，每
行一个文档、能指定来源列）、网页（自动剥掉 HTML 标签只留正文、带网址和标题）。这样后续的文
本分割、向量化就能用统一接口处理，不用管数据原始是什么格式。
