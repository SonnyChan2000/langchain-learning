Python 是一门解释型、面向对象的编程语言，语法简洁，适合快速开发和数据处理。它拥有极其丰富的第三方库生态。

AI Agent 是能够自主调用工具、完成复杂任务的智能体。它的核心是由大模型做决策，通过 Function Calling 调用外部工具，再根据结果决定下一步行动。

RAG（检索增强生成）是一种让大模型基于外部文档回答问题的技术。流程是：文档切块、向量化、建索引；用户提问时检索最相关的几段，塞进提示词，让大模型基于这些段落作答。

Prompt Engineering 是设计提示词引导大模型输出的技术。常用技巧包括角色设定、Few-shot 示例、思维链 CoT，能显著提升回答质量与稳定性。

Embedding（嵌入）把一段文字映射为一个高维向量，语义相近的文本向量方向更接近。常用模型有 text-embedding-v4 等，用于语义搜索和向量检索。

Node.js 是一门运行在服务器端的 JavaScript 运行时环境，常用于搭建后端服务和命令行工具。
